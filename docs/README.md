Описание
Сайт магазина настольных игр. Посетитель может посмотреть каталог игр, подобрать игру по числу игроков и длительности партии, открыть страницу любой игры, посмотреть корзину, доставку и контакты, отправить сообщение через форму обратной связи. Также реализована регистрация, вход в личный кабинет и оформление заказов с сохранением в базу данных.

Как запустить
Проект состоит из двух частей: Бэкенд (Python + FastAPI + SQLite) и Фронтенд (HTML + CSS + JavaScript). Для работы нужно запустить оба сервера.

1. Запуск бэкенда (Сервер и База данных):

Откройте терминал и перейдите в папку backend:

text
cd backend
Установите зависимости:

text
pip install -r requirements.txt
Создайте и наполните базу данных (создастся файл test.db с 17 играми и тестовым пользователем):

text
python seed.py
Запустите сервер:

text
uvicorn main:app --reload
Сервер будет доступен по адресу http://127.0.0.1:8000.

2. Запуск фронтенда (Сайт):

Откройте новое окно терминала (не закрывайте первое).

Перейдите в корневую папку проекта (где лежит index.html).

Запустите локальный веб-сервер:

text
python -m http.server 5500
Откройте в браузере адрес http://localhost:5500/catalog.html.

Что сделано
ПР 1: страницы и оформление
Семь страниц: главная, каталог, страница игры, корзина, о нас, доставка, контакты, личный кабинет.

Главная: подборка из 6 игр со ссылками на страницы игр.

Семантическая разметка: header, nav, main, article, footer, один заголовок первого уровня на странице.

Собственный логотип (images/logo.svg).

Макет на Flexbox и Grid, стили в одном файле.

Адаптивность: при ширине 360 пикселей горизонтальной прокрутки нет.

Доступность: alt у всех изображений, видимый фокус при навигации Tab, подписи полей формы.

ПР 2: поведение и внешние данные
Две интерактивные формы: фильтр каталога (число игроков, длительность партии, сортировка) и форма обратной связи на странице контактов.

Проверка данных до отправки: ошибки выводятся рядом с полем, а не во всплывающем окне. Фокус переходит на первое поле с ошибкой.

Содержимое меняется без перезагрузки: список игр фильтруется и сортируется сразу после выбора, счётчик и сообщение «ничего не найдено» обновляются автоматически, под каждой ценой появляется пересчёт в доллары и евро.

Внешний источник данных: курсы валют ЦБ РФ (https://www.cbr-xml-daily.ru/daily_json.js). Запрос выполняется через fetch и async/await. Пока данные грузятся, пользователь видит сообщение «Загружаем курсы ЦБ РФ…».

Обработка ошибок сети: если источник недоступен, появляется понятное сообщение и кнопка «Повторить загрузку». Каталог и цены в рублях при этом продолжают работать.

ПР 3: сервер и база данных
База данных SQLite: состоит из 4 таблиц со связями.

users (Пользователи): id, username (логин), password_hash (хеш пароля).

products (Каталог игр): id, name, price, min_players, max_players, play_time.

orders (Заказы): id, user_id (внешний ключ на users.id), product_id (внешний ключ на products.id), quantity.

messages (Обратная связь): id, name, email, message.

Наполнение базы: база содержит 17 игр с реальными названиями и характеристиками.

Сервер на Python (FastAPI): реализованы обработчики:

GET /api/products — список всех игр.

POST /api/register — регистрация пользователя.

POST /api/login — авторизация и выдача JWT-токена.

POST /api/orders — создание заказа (только для авторизованных).

GET /api/my-orders — получение истории заказов текущего пользователя.

POST /api/messages — сохранение сообщения из формы обратной связи.

Связь с интерфейсом: страницы каталога, профиля и корзины получают данные с сервера, а не из жестко прописанного HTML.

Защищенный контент: после входа пользователь видит свой профиль и историю заказов, недоступные неавторизованному пользователю.

Безопасность: пароли хранятся только в виде хеша (bcrypt), все SQL-запросы параметризованные (через ORM SQLAlchemy), склейки строк нет.

Как проверить
Каталог. Откройте catalog.html, игры должны загрузиться из базы данных (в консоли браузера будет запрос products со статусом 200).

Фильтр. Выберите «5 и больше» игроков и «До 30 минут». Список должен сократиться, счётчик — обновиться.

Курсы валют. Под ценами должен появиться пересчёт в доллары и евро. При отключении интернета появляется сообщение об ошибке и кнопка повтора.

Регистрация и вход. Откройте profile.html, нажмите «Зарегистрироваться», создайте пользователя (пароль от 6 символов). Затем войдите под ним — появится зеленый блок профиля.

Проверка хеширования. Откройте backend/test.db в DB Browser for SQLite, перейдите в таблицу users. В колонке password_hash должен быть длинный набор символов (хеш), а не пароль в открытом виде.

Заказы. Добавьте игры в корзину, нажмите «Оформить заказ». В profile.html в блоке «История заказов» появятся купленные игры.

Обратная связь. Отправьте сообщение через contacts.html. В таблице messages базы данных появится новая запись.

Адаптивность. В режиме устройства (F12, Ctrl+Shift+M) выставьте ширину 360 пикселей. Горизонтальной прокрутки быть не должно.
